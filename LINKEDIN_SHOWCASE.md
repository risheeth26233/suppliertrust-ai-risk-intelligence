# SupplierTrust — LinkedIn showcase

**Live fictional demo:** [suppliertrust-ai-risk-intelligence.vercel.app](https://suppliertrust-ai-risk-intelligence.vercel.app)  
**Source:** [GitHub repository](https://github.com/risheeth26233/suppliertrust-ai-risk-intelligence)

SupplierTrust is an evidence-led supplier due-diligence prototype. Its responsive command center connects supplier profiles, reviewer-recorded evidence, delivery observations, screening provenance, and explainable risk indicators for a clearer human review. Section guidance, keyboard/touch navigation previews, and an interactive tour help visitors understand the real workflow.

The public showcase is read-only and contains one fictional supplier with synthetic evidence and screening examples. Its risk index is deterministic; it is not a trained-AI prediction, a fraud probability, or a compliance decision. No live sanctions screening occurs in the public demo.

The local prototype includes supplier creation and editing, evidence records, PDF text extraction, cached OFAC SDN screening, reviewer decisions, delivery observations, audit history, and report downloads. GSTIN/CIN checks validate format only, and PDF extraction does not verify authenticity. No company registry or World Bank debarment API is connected.

Hosted showcase verification (2026-11-13): production frontend and API, fictional sample, all investigation pages, text report download, direct risk deep link, mobile layout, no browser console errors, and five read-only API guards.
