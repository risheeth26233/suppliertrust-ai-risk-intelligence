# API

`GET/POST /api/suppliers`, `GET/PUT/DELETE /api/suppliers/{id}`, `POST /api/suppliers/{id}/evidence`, `POST /api/suppliers/{id}/screen`, `POST /api/screenings/{id}/decision`, and `GET /api/suppliers/{id}/report`. Interactive schema is available at `http://127.0.0.1:8000/docs` while running locally. Screening uses a synthetic fixture only.
